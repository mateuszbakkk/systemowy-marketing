# systemowy.marketing

Strona metody „systemowy marketing” (marketing składany z klocków, które same się finansują).
Statyczny HTML, CSS i JS bez zależności, hostowany na GitHub Pages pod domeną https://systemowy.marketing.

- `index.html`: strona główna (metoda, klocki, ROMI, kalkulator, bootstrapping, pakiety, FAQ, kontakt)
- `sygnet/`: propozycje sygnetu z kostek (noindex)
- `assets/`: arkusz stylów i skrypt
- `znak/`: pliki znaku (SVG)
- Czat: widżet Czat Kooperatywa (`data-site="systemowy-marketing"`)
- Formularz: ta sama ścieżka co formularz lejki.pro (Discord, Notion, mail)

Operator: Kooperatywa.online sp. z o.o.
